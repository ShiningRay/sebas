# 命名

**Sebas**（2026-11-18 用户已裁决定名）—— 源自西语 Sebastián 常用昵称 Sebas，兼取《Overlord》纳萨力克首席管家 Sebas Tian 之名。第一轮候选（Seneschal 等 14 个侍从/管家/信使意象词）经用户裁决整体弃用，记录保留备查。

命名流程沿用 `tessell/docs/naming.md` 先例：候选 → 逐个 GitHub `in:name` 撞名核实 → 入围/落选 → 命名约定。本平台 = Crystal 多账号可编排 Personal Agent 平台（设计见 [design.md](design.md)），命名意象来源：多账号绑定（账号 = 被绑定侍从）、触发→条件→动作编排、免重启热更新、mrb.cr 插件层、Crystal 单二进制、Windows 优先、local-first。

## 定名推荐

**Sebas**：西语 Sebastián 的常用昵称；亦为轻小说/动画《Overlord》中纳萨力克地下大坟墓的首席管家 Sebas Tian 之名——「纳萨力克的大管家、昂星团（Pleiades）的监督者」（[维基百科 Overlord 角色列表](https://en.wikipedia.org/wiki/List_of_Overlord_characters)）。

一句话理由：**精确同名 GitHub 全部 ≤4★、无任何强势同名（对比：当年 Tessell 以 932 条仍判定干净可用）；Crystal 同名 shard 0；`ShiningRay/sebas` 实测 404 未被占用；非英文普通名词、无语义稀释——且「管家」意象恰好承接第一轮 Seneschal（总管）的核心意象，由用户亲自选定。**

意象对齐：

- 多账号绑定（email / 企业微信 / 飞书）＝管家经手的各户产业与侍从
- 触发→条件→动作编排＝管家按主人章程调度诸事
- 免重启热更新＝管家换班调度，不必惊动整个家宅
- Crystal 单二进制、Windows 优先、local-first＝常驻家宅的贴身管家

巧合佐证：同名仓库 hikire/sebas（2★）简介恰为「Loyal CLI aliases（忠诚的 CLI 别名）」——与管家意象同声相应。

风格与用户既有命名同系：autobot、fool、mrb.cr、Tessell——同为短小、全小写、非普通名词（Sebas 为人名昵称，无词典义稀释）。

## 第一轮记录（2026-11-18 用户裁决弃用，备查）

**Seneschal**：中世纪替领主统管全部产业与家务的首席总管。「为领主管理整片产业的总管是 seneschal，
其职责包括组织各项经营、核查所有账目并兼管家务运行」（Grosseteste《Reules》转述，
见[剑桥大学出版社《The Anglo-Norman Language and its Contexts》第四章](https://www.cambridge.org/core/books/abs/anglonorman-language-and-its-contexts/husbonderie-and-manaungerie-in-later-medieval-england-a-tale-of-two-walters/235A7EA4FDB22ED3BAA2B73A81055BDB)）。

一句话理由：**多个绑定账号 = 领主名下多处产业与侍从，触发→条件→动作编排 = 总管依章程调度诸事——Seneschal 直接命名本平台的核心机制「多账号统管 + 编排」，且 GitHub 同名仅 54 条、无任何强势同名（当年 Tessell 以 932 条仍判定干净可用）。**

意象对齐：

- 多账号绑定（email / 企业微信 / 飞书）＝总管名下多处产业、各户侍从
- 触发→条件→动作编排＝总管按章程处理事务流
- 免重启热更新＝总管换班调度，不必惊动整个家宅（免重启）
- Crystal 单二进制、Windows 优先、local-first＝领主常驻本地的贴身总管

风格与用户既有命名同系：Tessell（镶嵌/三角化，直指绘制路径）、celerite（拉丁）、mrb.cr、autobot——Seneschal 同为拉丁词源、全小写、意象直指核心机制。

4. 淘汰 9 个，入围 5 个，推荐 **Seneschal**。

### 落选原因

- **第一轮全体（用户裁决落选）**：Seneschal（首选）、Famulus、Housecarl、Castellan、Pontifex 五个入围候选撞名核实全部通过，但用户裁决「名字都不太好」，整体弃用——非撞名原因；侍从/管家/信使直译意象不再沿用，管家意象改由用户选定的 Sebas（借《Overlord》Sebas Tian）间接承接。
- **Familiar**（使魔意象原本最贴）：头部同名 familiar-software/familiar（204★）与本平台同为
  「个人 AI 助理 / 记忆与技能更新」领域，构成强势同名；且 familiar 为日常形容词，搜索独占性差。
  其使魔意象由拉丁词根 **Famulus** 继承入围——拉丁词典载 famulus 即
  「ein Diener, Aufwärter（仆役、侍者）」
  （[Lateinisches Synonymikon](https://archive.org/download/lateinischensyno01ramsuoft/lateinischensyno01ramsuoft_bw.pdf)），
  familiar（使魔）一词正源于此。
- **Squire**：fastmail/Squire 4928★ 知名富文本编辑器，已被占。
- **Herald**：头部同名仅 80★ 日志注解，无强势同名，但「herald」的新闻义（如各类 Herald 报）严重稀释搜索性；意象只及「传讯」，不及「多账号统管与编排」核心。
- **Errand**：runta-dev/errand（145★）「Persistent AI teammates with their own cloud compute」即同领域；另有 Errands 531★ 待办应用部分匹配。
- **Liaison**：liaisonio/liaison（204★）「Self-hosted access to private apps, LLMs, and AI agents」同域；且 Crystal 生态已有同名 shard [ModelArmy/liaison.cr](https://github.com/ModelArmy/liaison.cr)（面向 LLM 应用）——双重撞名。
- **Switchboard**：常见电讯词（2289 条），doctly/switchboard（364★）为相邻开发者工具。
- **Cairn**：耐久信标意象佳（首辅种子），但 oritera/Cairn 5341★ AI 状态空间搜索引擎 + cairn-dev/cairn 233★ 后台 agent 系统，AI 域已被占。
- **Lictor**：GitHub 仅 40 条、极干净，但 lictor（执束棒侍奉罗马官吏的侍从）所执束棒（fasces）正是「法西斯」名称与符号的直接来源——意象带政治毒性，常识检查不予通过。
- **Emissary**：emissary-ingress 4526★ 知名 K8s API 网关（前称 Ambassador），另有 NSA/emissary 331★，已被占。
- **Pontifex 入围但垫底**：「架桥者」意象偏离侍从/管家主线；Pontifex Maximus 为教皇正式头衔；2001 年 Chronic Logic 造桥游戏即名《Pontifex》（[维基百科 Bridge Builder 词条：系列含 Pontifex、Pontifex II/Bridge Construction Set](https://de.m.wikipedia.org/wiki/Bridge_Construction_Set)；[GameSpot 报道](https://www.gamespot.com/articles/garagegames-to-publish-pontifex-ii/1100-6071903/)），概念先占。
- **Housecarl 入围备查**：词义「中世纪北欧非奴仆性质的家臣侍卫，王室家臣兼有行政职责、任国王代表」（[Wikipedia: Húskarl](https://en.m.wikipedia.org/wiki/H%C3%BAskarl)），绑定 + 代办双重意象贴切；唯需接受 Skyrim 游戏玩家群的联想（同名 55★ 工具即 Skyrim 周边）。

## 命名约定

- Crystal 命名空间：`Sebas`
- 模块拆分建议（对应 [design.md](design.md) 四专章）：
  - `Sebas::Account` —— 多账号绑定（§5）
  - `Sebas::Orchestration` —— 触发→条件→动作编排引擎（§7）
  - `Sebas::HotReload` —— 免重启热更新（§11）
  - `Sebas::Plugin` —— mrb.cr 插件层（§12）
  - 渠道适配另设 `Sebas::Channel`（email / 企业微信 / 飞书，见 [research/channels-wecom-lark-email.md](research/channels-wecom-lark-email.md)）
- 后端/辅助 shard（若拆分）：`sebas-email`、`sebas-wecom`、`sebas-lark`（对齐 tessell-metal / tessell-vulkan 拆分法）
- 仓库：`sebas`；`ShiningRay/sebas` 2026-11-18 实测 404 未被占用，可建
- 环境变量与日志前缀：`SEBAS_` / `sebas`——与既有 `TESSELL_`、`AUTOBOT_` 前缀均不冲突
