算术自查（沿用已验收 WBS）：

- 各期估时：M0 = 17–25、M1 = 19.5–30、M2 = 12.5–19。
- M3 下限 1+1.5+2+4+4+3 = 15.5；上限 1.5+2+3+6+6+5 = 23.5
  （WP4/5 因 DSL/21 hook 各 +1 pd，包与生命周期此前已 +1.5–2.5 pd）。
- 总和：精确下限 17+19.5+12.5+15.5 = 64.5，精确上限 25+30+19+23.5 = 97.5。
  下表 M3 按对外区间取整为 15–24，故取整合计为 64–98.5。
- 含精确缓冲上限 107.5 pd（107.5/5 = 21.5 周，保守进位 W22）。

各期之间允许上一期末溢出顺延（周区间首端重叠表达此意），不做并行压缩。[推演]

M4 期排期与算术自查详见 B.8.4（2026-11-20 追加）。M4 入总计时以包区间 27.5–44.5 pd 为准
（小计 64.5+27.5 = 92，取整口径 64–98.5 + 27.5–44.5 → 总 91.5–143 pd，见 B.8.4 复算）。[推演]

**M5–M7 入总计的算术（2026-11-20 追加）**：

M5 22–36、M6 20–34、M7 6–10 → 新增 48–80 pd；与 M0–M4 的 91.5–143 pd 并计
= **139.5–223 pd**。周换算：

- 139.5/5 = 27.9 → 28 周（下限口径，末周 W28）。
- 223/5 = 44.6 → 45 周（上限口径，末周 W45）。
- 对外表述取 **28–45 周**，两端分别对应下/上限口径（不再写成 `W45/W46` 的合并式）。
- 含缓冲 +0–10 pd → 233/5 = 46.6 → 上限口径 **W1–W47**（下限口径 149.5/5 = 29.9 → W1–W31）。

M5–M7 内部算术详见 B.9.4。[推演]

**B.2 周号口径**：本表**两列均为全程序全局周号**，分别按「各期取下限估时」与
「各期取上限估时」两条独立时间线累加，允许上一期末溢出顺延到下期首端，**不做并行压缩**。

因此：

- 下限口径 M5 起于 W19、M6 起于 W23、M7 起于 W27。
- 上限口径 M5 起于 W29、M6 起于 W36、M7 起于 W43。
- 两种口径下 M7 起点都晚于 M6 门禁，与 B.1「M7.0-WP1 依赖 M6 门禁」不冲突。
- **已发布到 GitHub 的卡（#63–#93）沿用上限口径**；B.9.1 亦按上限口径书写。
- B.9.2/B.9.3 的块表用期内相对周号（`M5-W1`…），换算见 B.9 节首注
  （该处 `M5-W1 = W29` 亦为上限口径）。[推演]
